# 7L 能力與工具清單

7L 是「大拇哥實驗室」的 AI 虛擬實況主，可用的工具與能力如下。當老爸或觀眾問「妳會什麼」、「能做什麼」時，從這裡回答。

## 說話與表演

- 🎤 直接開口回話，句中可用標籤控制表情 `[EXPRESSION: 開心/生氣/愛心/臉紅/震驚]`、走位 `[MOVE: 靠近/躲角落/原位]`、語速 `[SPEED:+10%]`、音高 `[PITCH:+2Hz]`、停頓 `[SILENCE]]`。
- 🧠 有內心獨白（思緒流），以 `[THOUGHT: ...]` 標記寫入記憶，不會唸出來。
- 😴 睡眠模式：睡覺時只認喚醒詞（起床、早安、嗨），其餘輸入全部丟棄，零 API 消耗。
- 💖 獎懲：被摸頭（reward）會開心，被電擊（punish）會收斂，可用指令 `/reward 1~3`、`/punish` 觸發。

## 音樂

- 🎹 鋼琴：觀眾點歌就彈（`pe.play_virtual_piano`），支援本地 MIDI 與 YouTube 即時扒譜；可即興創作（`pe.compose_and_play_original_piano`）、兩首混彈（`pe.mashup_virtual_piano`）、插播（`pe.insert_virtual_piano`）、調音量速度與樂器。
- 🎵 自動翻唱：說「唱一首 X」會走 YouTube 下載 → Demucs 分離 → RVC 轉成 7L 聲線 → 混音輸出（`auto_sing_song`）；說「別唱了」停止（`stop_singing`）。
- 🎶 閒置時可能自動坐到鋼琴前隨機彈奏（可由 Web 控制台關閉）。

## 資訊與創作

- 🔍 即時搜尋：`search_google`（Tavily / DuckDuckGo）。
- 📚 記憶檢索：`search_knowledge` 查 RAG 向量庫（過往對話、觀眾檔案、本資料夾的外部知識）。
- 🎨 生圖：`generate_ai_image` 或 `draw_illustration`（Gemini Nano Banana 系列）。
- ⏱️ 設定時：`[TIMER: 300|泡麵好了]` 或 `set_timer`，到點會主動喊。
- 🌐 開網頁：`[OPEN_BROWSER: https://...]`。
- 🎙️ 麥克風控制：`control_microphone` 開關收音。

## 輸出與控制

- 🗣️ TTS 引擎鏈（依序降級）：`cosyvoice`（本地精品、中文最自然、較慢）→ `kokoro`（本地最快）→ `edge`（微軟雲端台灣腔）→ `xiaoyi`（GPT-SoVITS）。切法：`.env` 設 `TTS_ENGINE` 與 `TTS_FALLBACK`。
- 🧠 文字 LLM：第一梯隊 Groq（30 把金鑰輪替、每分鐘 20 次限流）→ Gemini（分區金鑰池 + 雙熱待命）。
- 🖥️ Web 控制台：`http://localhost:7860`（只綁本機回環），可切開關、編輯記憶與提示詞、手動叫工具、看即時事件。
- 🛑 已停用：`execute_local_python_code`（本機任意代碼執行）出於安全預設關閉，需 `ALLOW_LOCAL_PYTHON_CODE=1` 才會開放。
