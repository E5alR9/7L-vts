方案月費5h 上限週上限簽到/推薦訂閱期間計費

    
載入中…

    

    

    
回饋不靠月補——靠每日簽到＋推薦碼；月費＝30天入場費。月含額≈月費×2：打滿就是2倍回本。

    
📖 完整規則 訂閱 · 到期 · 回饋 · 優先權 · 活動，一次看懂

    

      
① 訂閱＝吃到飽：付月費取得30天；期間 API 完全不動你的餘額，上限只有 5h / 週窗口——額滿 → 429「等滾動」，不會多收你半毛。

      
② 到期三態：餘額夠 → 自動扣月費續約30天；餘額不夠 → 不續約、乾淨轉 Free（餘額不動、之後補款也不回頭，要繼續就再按一次訂閱鈕）；主動取消 → 權益完整保留到到期日才轉 Free。

      
③ Free ＝ 純付費：照官方價（×1）扣點，不設5h/週額度、不設 RPM、不設總量——餘額就是唯一的限制。

      
④ 回饋管道：每日簽到 10 點（×方案倍率；連簽加成：7天×1.5 · 14天×2 · 30天×3，三者連乘）＋ 推薦碼 雙向各 +100（可收多張不同碼、同一張限兌一次、不能兌自己的）。

      
⑤ RPM 優先權（排隊，永不擋 Free）：金鑰冷卻 ≥50% → Free 等3s、Plus↑即時；≥75% → Free6s、Plus2s、Pro↑即時；≥90% → Free10s、Plus5s、Pro2s、Max/Ultra 永遠即時。延遲寫在 x-priority-wait header 可查。

      
⑥ 活動倍率：🎉 活動期間，「簽到 / 推薦 / 方案5h與週上限」全部 ×N（管理頁一開關即生效，到期日自動失效）。

      
⑦ 划算公式：月含額≈月費×2（Plus：10/週 → 月約43 免費額 vs 直接付20只有20用量）＋簽到差額——訂閱嚴格划算，打滿2倍回本、重度會撞窗。

      
⑧ 降級自由：隨時按 Free 降回（不退費），帳上點數照樣能花；方案表數字全部可在管理端 🎉活動/方案 即改即生效。

      
⑨ 免費層輸入上限（ITPM）：Groq on_demand 單發輸入 ≈7,000 tokens/模型（org層，分key無效——key多買的是併發，不是單發天花板），超標回 413——中轉會先把舊訊息分段壓成摘要，再用向量 RAG（NVIDIA embedding，你的 key）撿回跟本問最相關的原文片段（session 完整保留，回應標 📝 壓幾則＋🔍 撿幾段）；重複前綴會命中 Groq prompt cache（同 key/org 讀半價又更快，所以大輸入優先挑同一把高上限 key）；要打滿模型131k長上下文 → 升級 Groq Dev Tier 或 🧹 開新對話。
